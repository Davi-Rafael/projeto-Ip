## Descrição Geral(atual) do Projeto
A ideia do projeto é ser um jogo retrô, no estilo Omori, que teria um total de 3 partes. Na parte inicial teríamos um mundo simples para que o jogador pergunte a npc's e encontre um objeto. Após o encontro do objeto, passa para a segunda fase, no qual será composta de um labirinto simples. Após ele, na fase final, terá uma mini boss fight, que será no estilo do Journey of the Prairie King no Stardew Valley, o personagem fica no centro de uma arena enquanto raios/monstros atacarão o jogador que terá que desviar para passar da fase e finalizar o jogo.
